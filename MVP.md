# LifeWorld MVP v0.1

## Product

LifeWorld is a personal world shaped by the life you live.

Users do not complete tasks.
They live their life.

The world remembers.

---

# MVP Goal

The first version tests one question:

"Will users come back tomorrow to see how their world changed?"

---

# Core Loop

1. Open LifeWorld

2. See personal world

3. Record today's life

4. AI understands the meaning

5. World changes slightly

6. User returns tomorrow

---

# Visual Direction

Style:

Cozy Isometric World

Reference:

- Stardew Valley
- Monument Valley
- Animal Crossing

Feeling:

Warm.
Quiet.
Personal.
Alive.

---

# First Screen

## World View

The first thing users see is their world.

Not chat.
Not tasks.
Not statistics.

The world is the product.

---

# Initial World

Day 0:

The user receives:

- Small house
- One tree
- Small piece of land
- A path leading into unknown areas

The world should feel unfinished but full of possibility.

---

# Daily Input

The AI asks:

"How was your day?"

The user answers naturally.

Example:

"Today I worked until late, but still practiced French."

---

# AI Understanding

AI identifies meaningful moments.

Examples:

Learning:

→ Tree grows
→ New books appear

Exercise:

→ Training area develops

Travel:

→ New paths appear

Important memories:

→ Memory points appear

---

# World Change

Changes should be subtle.

No:

- Level system
- XP
- Ranking
- Punishment

The user should discover changes naturally.

---

# Memory System

Important moments become permanent memories.

Examples:

- First trip
- Important achievement
- Personal milestone
- Meaningful day

---

# MVP Features

Required:

✓ Isometric world screen

✓ Small house

✓ Growth tree

✓ Daily input

✓ AI summary

✓ Simple world change


Not included:

✗ Multiplayer

✗ NPC system

✗ Complex city

✗ 3D exploration

✗ Social features

---

# Success Criteria

A user opens the app after 30 days and thinks:

"I want to see what my world has become."
